# Welcome

This is your computer. It's a real Linux machine, running just for you, and
it stays around between sessions — nothing here disappears when you close the
tab.

## What's here

A minimal Next.js project (`package.json`, `pages/index.js`). It's deliberately
small: enough to run, not enough to get in your way. Delete it, replace it,
or build on top of it — it's yours.

## What's installed

- VS Code, open right now to this folder
- A browser, for looking at what you build
- Node/Bun and the usual JavaScript tooling, so `npm`/`bun`/`pnpm` all work

## How to start

The dev server is already running. Edit `pages/index.js`, hit save, and watch
the preview change.

If you ever need to (re)start it by hand:

```
bun install
bun run dev
```

It listens on port 3002 — that's the port this environment always previews
for you, so you don't need to think about it.

## If you want a completely different project

Delete everything in here and start fresh — `npx create-next-app@latest`,
clone a repo, whatever you want. This was just a starting point, not a cage.
