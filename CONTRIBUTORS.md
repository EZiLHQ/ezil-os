## How this list is maintained

`git shortlog -sne` is the source of truth for who has committed. A [`.mailmap`](.mailmap)
canonicalises identities so the same person committing under different names appears once.
If you contribute and want to be listed here, add yourself in the same pull request —
see [`CONTRIBUTING.md`](CONTRIBUTING.md).

## A note on machine assistance

Parts of this codebase were written with AI assistance. Where that is the case the commits
carry a `Co-Authored-By:` trailer, so the record is in the git history rather than only in
this file. Authorship, review and responsibility for what ships rest with the human authors
listed above.
